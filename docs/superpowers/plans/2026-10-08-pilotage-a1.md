# Pilotage A1 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/pilotage` affiche une seule période pour toute la page, un seul chiffre par notion, sans évolution, avec des listes de détail complètes (lots) — sans changer les règles de calcul existantes.

**Architecture:** L'état de période remonte dans `PilotageClient` et descend en prop dans `AnalytiquesTab`. Les calculs purs de `lib/pilotage/calculs.ts` s'enrichissent (lignes de détail, drapeaux de conversion, éléments de qualité liés) ; `lib/actions/pilotage.ts` ne fait que lire et mapper. Les anciens taux (`winRate`, `tauxConversion`, `tauxGainGlobal`, `lots`) sont retirés de bout en bout : types → actions → composants → exports.

**Tech Stack:** Next.js 15 (App Router, Server Actions), React 19, Prisma 7, shadcn/ui, Recharts, ExcelJS, Playwright (tests unitaires via `playwright.unit.config.ts`, E2E via `playwright.config.ts`).

**Spec:** `docs/superpowers/specs/2026-10-08-pilotage-a-design.md` (tranche A1). PRD : `docs/PRD-pilotage-a.md` (non versionné).
